搜索用的原生文字版

Publications、Projects、Events、Teaching 是整页 embed，Google 收录了页面却读不到里面的字。给每个板块建一个隐藏的"文字版"子页面，把下面对应的块粘进去即可。生成于 2026-10-02；内容有变化的块会标"有更新"。重新生成：NODE_PATH=$(npm root -g) node seo/sites_text.js

  1. 在 Sites 里，每个板块下面新建一个子页面（下表），右键 → Hide from navigation；页面设置 → Advanced 里填自定义路径。
  2. Publication List：https://yufeiding.ucsd.edu/publications/list（放在 publications 下面）
  3. Project Overview：https://yufeiding.ucsd.edu/projects/overview（放在 projects 下面）
  4. Lab News：https://yufeiding.ucsd.edu/events/news（放在 events 下面）
  5. Course List：https://yufeiding.ucsd.edu/teaching/courses（放在 teaching 下面）
  6. 每个子页面放一个文本框，粘贴对应的块（会带着标题、粗体和链接）。
  7. 在 Home 页已有的文字下面加一行"文字版入口"（最后一块），让 Google 能顺着链接找到这些子页面。
  8. Publish 后在 Search Console 对四个新网址点 Request indexing。以后某块标了"有更新"，就重新粘贴那一块。

Project Overview - Picasso Lab, UC San Diego

Projects and live demos from Picasso Lab at UC San Diego (Prof. Yufei Ding). Interactive version: https://yufeiding.ucsd.edu/projects

Qubrio (Quantum Computing)
A multi-agent LLM compiler for neutral-atom quantum computers. Placement, routing and optimization agents, checked by deterministic verifiers, move atoms in convoys: 4.7× lower hardware runtime and 1.3× higher fidelity than PowerMove, the state of the art.
Topics: Quantum Compilation, Multi-Agent, LLM

TritonGym (LLM Benchmark)
An ICML 2026 benchmark for LLMs that write Triton GPU kernels inside agentic workflows. 164 operators, four agent strategies and a live leaderboard that ranks models on correctness and on speed against hand-tuned kernels.
Topics: Triton, LLM, Benchmark, ICML 2026

TritonDFT (AI for Science)
A multi-agent system that runs Density Functional Theory end to end, from a plain-language question to a converged result. Planner, Executor, Analyzer and Refiner agents pass 98% of DFTBench, 68× faster than by hand, at an average $0.04 per material.
Topics: DFT, Materials Science, Multi-Agent

ChipMATE (Chip Design)
A self-trained multi-agent framework for Verilog generation. A Verilog agent and a Python reference-model agent check each other cycle by cycle on random inputs, with no golden testbench. The 9B model scores 80.1% on VerilogEval v2, ahead of DeepSeek V4, a model about 200× larger.
Topics: RTL, Verilog, Multi-Agent, EDA
