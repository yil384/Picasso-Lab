# Yufei's anime short (double-click on her Team-page avatar)

- `art/`: the painted images (ChatGPT image generation from `art/y_ref.png`, the approved chibi design; prompts in
  the chat history: one style paragraph + one line per image, poses / cat / gremlins on flat #00FF00).
- `tools/key.py`: keys the green sprites into `cut/` (generated, not committed); the gremlins sheet is split into
  `cut/grem0-2.png` by connected components (see the commit that added it).
- `film/anime.html` (+ `lib2d.js`): the 8 s scene for the video-kit pipeline (branch `video-kit`). To render: copy
  `film/` to `video-kit/films/yufei_anime/`, put `cut/*.png`, `art/bg_*.png`, `photo_full.png`, `comic_sky.png`,
  `comic_palm.png` into its `assets/`, then
  `cd video-kit/pipeline && python3 ../films/yufei_anime/tools/pv.py render ../films/yufei_anime/anime.html --out ../out/yufei_anime/r960 --width 960 --height 960 --workers 2 --store png`
  and encode to 480 (mp4 H.264 + webm VP9) -> `people/static/film/yufei.{mp4,webm}`.

## The current film: 18 s, 3D-animated-movie style (`film/film18.html`) - this is what is live

History (the user's verdicts, worth remembering for any avatar film):
real-photo panels with comic effects ("人物不能只是背景板": the person must be the animated protagonist) ->
a chibi built from code primitives ("太垃圾") -> the 2D painted set above (8 s, "太短了，风格太粗糙") ->
**3D animated-movie look with heavy three.js** (approved). Lesson: characters come from painted art, not code;
three.js builds the world, camera and light around them.

- Art: `art3d/` - 24 images generated by the user in ChatGPT from `art/y_ref3d.png` (the approved 3D design),
  each on flat #00FF00: 15 Yufei poses (`y_pop` ... `y_wave`), 4 cat poses, the gremlins sheets
  (`gremlins`, `grem_burst`, `grem_dizzy`, three each), and the backgrounds `bg_lab.png`, `bg_sunset.png`.
  Key them: `SRC=art3d OUT=cut3d python3 tools/key3d.py` (`cut3d/` is generated, not committed). The gremlin sheets are
  split into `<name>_0..2.png` by connected components (no dilation, alpha > 140, or two gremlins merge).
- Scene: `film/film18.html` (432 frames @ 24 fps, 960x960 render, not a loop: starts and ends exactly on her photo).
  A three.js lab desk in front of a sunset window, a real 3D quantum chip, warm key light with soft shadows, dust
  motes, a 3D gold paint ribbon; the painted cut-outs stand in the world as shadow-casting billboards; the camera
  orbits, whips and crash-zooms. Shot list in the comment at the top of the scene. `film/lib2d.js` = 2D lettering
  and effects drawn on top.
- Render (video-kit pipeline, branch `video-kit`, a local worktree): copy `film/` to
  `video-kit/films/yufei_anime/`, the cut-outs + backgrounds + `photo_full.png` into its `assets3d/`, then
  `cd video-kit/pipeline && python3 ../films/yufei_anime/tools/pv.py render ../films/yufei_anime/film18.html --out ../out/yufei_anime/f18 --width 960 --height 960 --workers 2 --store png`.
  Check stills first (`pv.py nshoot`, `film/tools/sheet.py` for a contact sheet) and show them to the user before
  the full render.
- Encode to 480x480: H.264 high (crf ~27, `+faststart`) -> `people/static/film/yufei.mp4` (~1.2 MB) and VP9 ->
  `yufei.webm` (`film/tools/finish.py` does both and checks the size). Wired in `people/fx/yufei.js` with
  `film: 'film/yufei'` (kit.js plays it inside the round avatar on double-click). The avatar snippet does not change,
  so no re-paste is needed for a new film - only the push.
