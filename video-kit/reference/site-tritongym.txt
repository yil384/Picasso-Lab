Dataset The benchmark spans 164 operators across three splits: Standard — 139 common GPU kernels (matmul, attention, normalization, activations, quantization, …) with reference PyTorch implementations and oracle Triton kernels. OOD — 13 novel operators less likely to be in pre-training corpora. DSL — 12 operators specified in domain-specific languages (Gluon, TLX), evaluating the generalization of agents to new programming abstractions. Each operator is evaluated on multiple input shapes. Correctness uses a max-absolute-error threshold of 0.01 against the PyTorch reference; performance is the latency ratio against the oracle Triton kernel. Operator coverage across the standard / OOD / DSL splits. Agentic Workflows TritonGym standardizes tool access (compilation, verification, profiling) so workflow design can be evaluated independently of the underlying LLM . Four workflows ship out of the box: One-shot Single-pass generation from the operator spec — the lower bound on what an LLM can do without feedback. Geak Multi-agent pipeline with generator, compiler, verifier, optimizer, and reflector roles. AlphaEvolve Iterative refinement using evaluator feedback (up to 5 attempts ).
